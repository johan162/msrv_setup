B.2 How to create filter that matches on any of several rules (creating an “OR” rule)

By default all matching rules in a filter need to apply before the action is taken. To create a rule which simulates an “OR” condition for the matching expression one has to make use of the “else” rule. This is done by executing an empty action “{ }” when all the conditions do NOT match and our “real” actions if this condition is not true. (This uses the fact that NOT( (NOT A) AND (NOT B)) = A OR B )

:0 hb
* !<expression 1>
* !<expression 2>
{ }

:0 E
<action to be taken>

Please note that there should be one space in the “{ }” empty statement!

So for example to store mail that comes from either ´"<joe.r@gmail.com>" or “<helen.q@gmail.com>” in a folder called “Friends” the following recipe could be used

0: hb
* !^From:.*joe.r@gmail.com
* !^From:.*Helen.q@gmail.com
{ }

:0 e
$FRIENDS
