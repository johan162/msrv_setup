Appendix A - Postfix configuration examples

One key to configure postfix SMTPD access is to understand the configurations directive smtpd_recipient_restrictions. Below are two examples on how this can be used. Remember that the order of the settings in this configuration is important. Postfix will execute them sequentially

A.1 Example 1

The default settings will only allow anyone on the same subnetwork as the server to send relay mail through

mynetworks_style = subnet # only allow clients on the same subnet to connect

smtpd_recipient_restrictions = 
  permit_mynetworks
  reject_unauth_destination
