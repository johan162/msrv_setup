11 Where to find more information

Seeing that this description has taken far too many pages and still hardly can be called complete one has to realize that it's not completely trivial to setup a fully working mail server. There are many sidetracks we have avoided or just scratched on the surface on to keep this HowTo from becoming a fully-fledged book. However we hope that this description has provided a good overview and points of interest worthy of further study. Below we have listed some sources of information for the different tools we have described here.

11.1 On the usage of SuSE Yast tool

Using Yast might at times seem tempting however the setups possible via Yast are limited and doing anything just outside the very basic setup is often not possible. In addition some necessary configurations comes from manipulating /etc/sysconfig file where documentation is scarce.

For that reason one has to manually configure most setups. In addition there are some differences in the SuSE setup files compared with some tools default setup. In most cases these changes are done to improve upon the standard delivered files. However lack of proper detailed documentation makes it necessary to very carefully read through a whole lot of system and internal configuration files that SuSE uses (but no-one else) to really understand, for example, how a program is started.

In addition there are several utility scripts available that can help with mundane tasks but since they are not documented (or that the documentation is successfully hidden!) it's difficult to know about them.
