B.4 Replying with a mail based on subject

This shows how to use formmail to perform an action based on the subject of an incoming mail. In this particular case we respond to a specific mail by powering on a remote server

#---------------------------------------------------------------------------
# Sending a reply based on subject
#---------------------------------------------------------------------------
:0 h c
* ^Subject: gwake
| (/usr/bin/formail -r -I"Subject: Server gamma waking up (autoreply)" ; \
echo "This is not a guarant\
ee that the server has woken up though. " ) | $SENDMAIL -t
