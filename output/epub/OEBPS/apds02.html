D.2 master.cf

For a setup that uses port 25 both to received encrypted and non-encrypted communication it is enough to just uncomment the following line in the default master.cf 

tlsmgr    unix  -       -       n       1000?   1       tlsmgr

To enable either the submission port (587) or the (obsoleted) SMTPS port (465) it is necesary to adjust master.cf so that SMTPD listens on that port.
