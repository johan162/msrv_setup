F. Apache virtual host example configuration

The following example configuration shows a complete virtual host configuration for a HTTPS server. The configuration assumes that the host is at IP address 192.168.0.50. You should also notice that this setup relaxes the overly restrictive default settings to allow symbolic links and CGI programs to be executed.

Remember also that in addition to the virtual host configuration file the /etc/sysconfig/apache2 configuration also needs to be updated as described in a previous chapter to allow HTTPS traffic.

ssl-vhost.conf

The following shows an example of a complete virtual host configuration

Note

The initial <VirtualHost _default_:443> will make these settings apply on all IP addresses that no other virtual host is bound to. Please observe that this is quite different from <VirtualHost *:443> which will match all IP addresses regardless if they are used by other virtual host or not.

The matching is valid only for numeric IP add not DNS names.

<VirtualHost _default_:443>

        #  General setup for the virtual host
        DocumentRoot "/srv/www/vhosts/ssl-htdocs"
        ServerName 192.168.0.50:443
        ServerAdmin root@localhost
        ErrorLog /var/log/apache2/ssl-htdocs.err
        TransferLog /var/log/apache2/ssl-htdocs.access
        CustomLog /var/log/apache2/ssl-htdocs.info   ssl_combined

        DirectoryIndex index.html

        RewriteEngine On                                                                     
        RewriteOptions Inherit                                                               
                                                                                             
        HostnameLookups Off                                                                  
        UseCanonicalName Off                                                                 
                                                                                             
        ServerSignature On                                                                   
                                                                                             
        Include /etc/apache2/conf.d/*.conf                                                   
                                                                                             
        <Directory /srv/www/vhosts/ssl-htdocs>                                               
          AllowOverride All                                                                  
          Options Indexes FollowSymLinks ExecCGI                                             
          Order allow,deny                                                                   
          Allow from all                                                                     
        </Directory>                                                                         

        ScriptAlias /cgi-bin/ /srv/www/vhosts/ssl-cgi-bin
        <Directory /srv/www/vhosts/ssl-cgi-bin>
          AllowOverride All
          Options +ExecCGI -Includes
          Order allow,deny
          Allow from all
        </Directory>

        SSLCertificateFile /etc/apache2/ssl.crt/server.crt
        SSLCertificateKeyFile /etc/apache2/ssl.key/server.key
        SSLEngine on
        SSLProtocol all -SSLv2 -SSLv3
        SSLCipherSuite ALL:!aNULL:!eNULL:!SSLv2:!LOW:!EXP:!MD5:@STRENGTH

        <Files ~ "\.(cgi|shtml|phtml|php3?)$">
            SSLOptions +StdEnvVars
        </Files>
        <Directory "/srv/www/cgi-bin">
            SSLOptions +StdEnvVars
        </Directory>

        SetEnvIf User-Agent ".*MSIE [1-5].*" \
                 nokeepalive ssl-unclean-shutdown \
                 downgrade-1.0 force-response-1.0
                 
</VirtualHost>
