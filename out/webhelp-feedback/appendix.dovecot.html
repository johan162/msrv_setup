C. Dovecot tips and tricks

Automatic expunging of old mails

Subscribing to non-personal mail like newsletters and mail lists tends to grow the mailbox quit a lot with information that usually is valid only for a short time. So having this kind of mail automatically deleted after a certain time period, say 2 weeks, is usually a good thing.

Dovecot provides a utility program called doveadm that can do exactly this. Among other things doveadm have a command "expunge" to delete all mails that matches a certain search criteria in a specified mailbox.

An example will clarify how this work. Assume we want to delete all mails older than two weeks in our "dovecot" mail folder. To do this we search and delete all mails that were stored in that mail folder more than fourteen days ago with the command:

/usr/bin/doveadm expunge mailbox dev.dovecot savedbefore 14d

All messages older than 14 days in the mail folder “dev/dovecot” have now been deleted.

In Linux we can then setup a cron job that calls a script with these expunge command at regular intervals, say once a week or even once a day.

The search commands for doveadm are quite flexible so please look at the man page for other search options. The above line will cause all mails (both read and unread) to be deleted. One common modification is to have non read messages kept longer.

If we store the above line in a script as

#!/bin/sh
/usr/bin/doveadm expunge mailbox dev.dovecot savedbefore 14d

and store the script as, say, /usr/local/bin/user-expungemail we can then uses a cronjob to call this script a regular intervals. Having the jobs called every Wednesday and Sunday at 3 a´clock in the morning would for example require us to write

0 3 * * 3,7     /usr/local/bin/user-expungemail

If the server have multiple accounts each will need its own expunge cron job script run as the user that owns the account.
