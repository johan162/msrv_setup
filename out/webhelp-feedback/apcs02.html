Synchronizing (or backing up) two IMAP servers

If you have two IMAP server setups and you want to synchronize them you can use the dsync command (which belongs to Dovecot) this can either be used to make a complete backup of a IMAP server and it can also be used to synchronize between two IMAP servers.

Example 1. Making a complete backup to a remote server

Make sure that the user exists on the remote server and then make sure that the destination is empty the first time you run the backup command to avoid any conflicts. Assuming the user is “joe” and the remote server is located at IP address 192.168.0.51.

Login as root (on this server, the source) and then give the following command 

$>  dsync –u joe –v backup root@192.168.0.51 -u joe

Dsync will now use ssh to login to the remote server and copy all the mails from this server onto the remote server for this user.

Example 2. Synchronizing between two servers

The difference between backup and synchronization is that any changes in the remote server will also be reflected back in the source server. Assuming the same user and server as In the previous example this is now done by as so

$>  dsync –u joe –v mirror root@192.168.0.51 -u joe
