Generating the Dovecot/postfix key-pair

This is done exactly analogue (but with the obvious change of filenames) as when we created the HTTPS key-pair. The commands to create the key-pair are the following.

First create the signing request

$> openssl req -new -nodes -keyout private/mail_private.pem \
-out csr/mail_public.pem -config ./out_openssl.cnf

And then signing this request with our own root certificate

$> openssl ca -out public/mail_public.pem -config ./our_openssl.cnf \
-infiles csr/mail_public_req.pem

These lines have now created the following files

  • private/mail_private.pem, The private key for our mail setupcc

  • public/mail_public.pem, The public key for our mail setup

  • csr/mail_public_req.pem, The signing request. This is not needed any more but could be kept to re-generate the certificate when it expires in 10 years.

  • newcerts/02.pem, A copy of the signed certificate for our records as a certification agency
