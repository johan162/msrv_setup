A template to start with

The final example is not really an example but a template that you may use to get a good start in writing your own rules. It give a logical structure and establishes some "best practices" to get readable and understandable procmail files (as far as that is possible). This template will give you

  • A logfile under /tmp for each month

  • Spamfiltering based on spamassassin with both filtering to a "Spam" folder and also direct deletion of mails with a high spam score (>=15)

  • A good practice of giving symbolic names to the mail folders where to store mail

#---------------------------------------------
# Standard setup for extra logging
#---------------------------------------------
VERBOSE=on
LOGABSTRACT=all
LOGFILE=/tmp/procmail-${LOGNAME}-`date +%Y%m`.log
 
#---------------------------------------------
# Some standard paths
#---------------------------------------------
MAILDIR=/srv/mail/${LOGNAME}
DEFAULT=${MAILDIR}/
INBOX=${MAILDIR}/
 
#---------------------------------------------
# Subfolders to store mails in. You should add
# a variable for each folder you are using in your
# mail setup. The wasiest way to create the proper
# folders is to do it via you email client,
# REMEMBER TO PUT TRAILING '/' AT THE END 
# to mark that the folders are in maildir format.
#---------------------------------------------
SPAM=${MAILDIR}/.Junk/
NEWSLETTERS=${MAILDIR}/.newsletters/
 
##--------------------------------------------
## End of setup. Now comes all the filer 
## rules.
##--------------------------------------------
 
#---------------------------------------------
# FILTER all Newsletters.
#---------------------------------------------
:0
^Subject:.*Newsletter
^From:.*news.com
{ }
:0 E
$NEWSLETTERS
 
#---------------------------------------------
# FILTER for spamassassin. Only run mails smaller than ½ MB 
# through spamassassin
#---------------------------------------------
:0
* < 512000
| /usr/bin/spamc
 
#---------------------------------------------
# Delete all spams with score >= 15 
#---------------------------------------------
:0
* !^X-Spam-Level: \*\*\*\*\*\*\*\*\*\*\*\*\*\*\*.*
* !^X-Spam-Status: Yes, score=1[5-9]\.[0-9]
* !^X-Spam-Status: Yes, score=[2-9][0-9]\.[0-9]
{ }
:0 E
/dev/null
 
#---------------------------------------------
# Put all remaining identified spams in Junk folder.
# NOTE: This assumes spamassassin is configured to 
# set the X-Spam-Flag: YES for identified spams.
#---------------------------------------------
:0
* ^X-Spam-Flag: YES
$SPAM
 
#---------------------------------------------
# Store the reaming mails to the inbox
#---------------------------------------------
:0
$DEFAULT
