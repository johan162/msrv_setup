Setting up Roundcube

(Note: The following section assumes that roundcube v0.7 and MySQL community server have been installed, see the section called “Applicable OpenSuSE versions and pre-requisites”)

We have finally come to the part that users will see; the Web-based mail client. To setup Roundcube do the following steps:

  1. Download Roundcube from http://roundcube.net/

  2. Extract the sources to your SSL enabled http document root. We also recommend to change the main directory name for Roundcube to something more generic, say "webmail". Using the structure suggested previously in this document this would then be ‘/srv/www/ssl-htdocs/webmail’ and will make it possible to access your mail in a natural way as "https://localhost/webmail/"

    Tip

    One alternative way of placing Roundcube sources is outside the document root, say “/usr/local/share”. Then we create an Apache alias to that directory. This means that if the user accesses (for example) “/webmail” Apache knows that it should actually fetch the content from the directory “/usr/local/share/roundcube” assuming we have setup our aliases in that way. Please refer to the Apache documentation for more details on the alias command. This is a good practice to avoid installing Web-applications directly in the document root.

  3. Make sure that the Web-server can write to ‘temp’ and ‘logs’ directories within the extracted files in the document root by executing the following command as root

    $> chown -R wwwrun:www temp logs

  4. Setup the MySQL user and database that roundcube should use as follows (this assumes that you previously have installed MySQL and have set a password for the root user.)

    $> mysql –h localhost –u root -p
CREATE DATABASE roundcubemail;
GRANT ALL PRIVILEGES ON roundcubemail.* TO roundcube@localhost \
IDENTIFIED BY 'roundcube';
FLUSH PRIVILEGES;

    Note: You can change the user and password to something better but since the database is only accessible from localhost it is still quite secure.

  5. Point your browser to the installer directory https://webmail/installer/

    The installation is a three step process. The first step is a verification that the PHP5 installation has all necessary modules installed. Verify that all the necessary prerequisites are fulfilled.

    In the next step the details of the database, the IMAP and SMTP settings must be given. Below are some examples on how this can be specified (change user and passwords according to your settings)

    Table 10. Roundcube SMTP settings

    FieldValue

    Note: Please leave the SMTP username and password empty. Roundcube will then use the login information to access the SMTP user.

    In the next step the installer will show the two configuration files "main.inc.php" and "db.inc.php". Download them and store them in the config directory.

    The final step in the setup is a test to make sure that the settings are correct. Make sure that all these tests succeeds before proceeding!

  6. It should now be possible to point your browser to the directory where you have installed Roundcube (https://localhost/webmail/) and see the interface. After making sure that this works the installer directory should be removed.
