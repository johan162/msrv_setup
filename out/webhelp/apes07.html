Keeping both the certificate and key in the same file

It is useful to know that if some servers only give you the option to specify one SSL/TLS file you must combine both the public (certificate) and the private key in one file. You can easily do this as

$> cat private/mail_private.pem public/mail_public.pem > mail_combined.pem

You could also do this for Dovecot and postfix since they will read the correct key based on the headers in the file. Some might think that this is better way of keeping out key-pair since we can never lose one key in the key-pair if we keep them combined.
